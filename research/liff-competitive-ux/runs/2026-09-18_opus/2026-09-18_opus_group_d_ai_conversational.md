# Group D — AI / Conversational Finance

## Summary
This report analyzes the competitive landscape of AI-driven conversational finance products to inform the development of MaewSom (แมวส้ม). The research covers 11 products (including a new 2026 entrant, Ask Zopa) across 22 dimensions, with deep dives into Cleo and Rocket Money/Rowan. Key areas of focus include AI agentic capabilities, proactive vs. reactive behaviors, personality tone-mapping, and how systems establish—or break—user trust in high-stakes financial environments.

## Deep Dive: Cleo
**Transaction Lifecycle:** 
Passive detection via API -> AI auto-categorizes -> Confidently asserts without asking for confirmation -> Translates finding into an emotional "Roast" or "Hype" -> Prompts an "auto-save" action as penance or reward.
**Personality Modes:** 
Roast mode drives virality but becomes a massive liability when users are in actual distress (e.g., job loss, systemic poverty). Roasting structural issues rather than discretionary spending destroys trust.
**Handling Serious Situations:** 
Designed to scale back sass when accounts go negative, but automation edge cases (e.g., a meme about being broke sent to someone facing eviction) cause severe friction.
**Chat vs Dashboard Balance:** 
Aggressively chat-first; the dashboard is buried, frustrating power-users who want traditional ledgers.
**AI Complaints:** 
Users complain the AI is an "illusion" of decision trees, leading to repetitive loops and an inability to learn from manual category corrections.

## Deep Dive: Rocket Money / Rowan
**Integration:** 
Bypasses the app entirely, operating primarily via native SMS/RCS texts. Sends deep links only when visual confirmation is required.
**Proactive vs Reactive:** 
Highly proactive; initiates conversations based on data streams (e.g., forgotten trials).
**Transaction Lifecycle:** 
Monitors data -> Identifies anomaly -> Proactively texts user -> Asks for strict confirmation ("Should I cancel?") -> Executes real-world action (calls merchant).
**Confidence Handling:** 
Relies on a strict confirmation model for any agentic action. Hands off to human support when uncertain.
**Action Capabilities:** 
True agentic capabilities: negotiating bills, canceling subscriptions, and updating budgets autonomously.

## AI Trust Framework (Cross-Product Analysis)

**1. Building Trust:**
Trust is built through transparency and privacy. Starling's local-cloud execution and Ask Zopa's visual auditability mode establish trust, whereas BofA's Erica builds it through a flawless "human bridge" and zero hallucinations. Hiding the "why" behind AI actions (Albert, Copilot) instantly creates "scam anxiety."

**2. AI Confidence Communication:**
Products handle confidence differently: Rocket Money requires explicit text replies for agentic actions; Copilot uses frictionless Approve/Dismiss UI for uncertain categorizations; Zopa uses rich visual cards before executing transfers. Never let AI confidently execute a high-stakes action without confirmation.

**3. When Personality Helps vs Hurts:**
Personality (Cleo) breaks the "ostrich effect" (avoiding looking at finances) via gamification. However, it hurts tremendously during high-stress moments. Wells Fargo and Cleo both suffered when their bots sounded condescending or tone-deaf during overdraft scenarios. MaewSom must ensure its cat persona defaults to polite empathy (Service Mind) when balances drop.

**4. Proactive vs Reactive Balance:**
Users ignore passive dashboards, making proactive AI valuable. Rocket Money's SMS alerts are highly effective, but risk feeling like spam. Copilot's contextual nudges inside the UI are the safest balance, alerting users exactly where the data lives.

**5. Transitioning to Serious States:**
When stakes are high, the AI must drop the persona. Cleo attempts this but fails in edge cases. Starling introduces "Scam Intelligence" friction for large transfers. BofA provides the gold standard: immediately handing off the entire chat context to a human agent so the user doesn't have to repeat themselves.

## Negative Review Analysis
Across the 11 products (2025-2026 data), user complaints center on:
1. **Hallucinations & Math Failures:** Users of Monarch frequently cite the AI making up aggregate sums, completely breaking trust.
2. **"Loop of Hell" / Poor Intent Recognition:** Erica and Fargo trap users in repetitive conversational loops instead of handing them to a human when NLP fails.
3. **Predatory Agentic Actions:** Rocket Money users complained about the AI negotiating contracts that triggered hidden 35-60% success fees without sufficient upfront clarity.
4. **Condescension:** Wells Fargo's AI and Cleo's AI were both explicitly cited for sounding condescending when users were vulnerable.
5. **Black-Box Rules:** Copilot and Albert users express deep frustration when AI auto-categorizes or auto-saves money and the user has no UI panel to see *why* or how to delete the rule.

## Key Findings for MaewSom
- **LINE Integration:** Utilize LINE's Flex Messages (similar to Zopa/Copilot) to provide rich visual confirmations before the MaewSom cat takes any agentic action.
- **The Human Bridge:** If MaewSom fails to understand a Thai query twice, instantly hand off the context to a human LINE agent. Do not trap users in a loop.
- **Tone Mapping:** The "Sassy Cat" persona must be dynamically disabled if a user's account hits zero. Thai culture heavily penalizes condescension; maintain a polite, service-minded tone for serious matters.
- **Pre-filled Chips:** Avoid the blank-page problem (Starling) by giving users conversational quick-reply chips in LINE so they know what MaewSom can do.
- **Approve/Dismiss UX:** Use gamified, 1-tap Approve/Dismiss flows (Copilot) for categorizing Thai PromptPay transfers, as OCR/NLP often struggles with localized merchant names.
